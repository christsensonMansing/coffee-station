# Coffee Station

Welcome to **Coffee Station**! A touchless attendance system using face recognition and QR code scanning to track employee time in and out. Employees can clock in/out by scanning their QR code or using facial recognition, ensuring accurate and secure time tracking.

## Features

- Real-time attendance dashboard
- Touchless clock in/out via QR code and facial recognition
- Employee management (add, edit, remove users)
- Attendance history and reporting
- Integrated business calendar for leave and events
- Announcements and notifications system
- Admin and user roles with secure authentication
- User-friendly interface

## Getting Started

### Prerequisites

- [Git](https://git-scm.com/)
- [Git LFS (Large File Storage)](https://git-lfs.github.com/)  
  > **Note:** This repository uses Git LFS because some files are too large for standard Git.  
  > You must install Git LFS before cloning or pulling the repository to ensure all files are downloaded correctly.

### Installation

1. **Install Git LFS**  
   Follow the instructions at [https://git-lfs.github.com/](https://git-lfs.github.com/) to install Git LFS for your platform.

2. **Clone the repository**
   ```sh
   git lfs install
   git clone https://github.com/your-username/coffee-station.git
   ```

3. **Install dependencies**  
   Navigate to the project directory and install dependencies as required (e.g., using `npm install` or `pip install -r requirements.txt` depending on your stack).

4. **Run the project**  
   Follow the instructions in the relevant section (see below) to start the application.
